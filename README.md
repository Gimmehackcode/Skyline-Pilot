# Skyline Pilot

A simple aircraft arcade game. Fly through gaps between city buildings and beat your best score.

## Play

Download `index.html` and open it in your browser. Everything is included in this single file; no installation or server is needed.

Press **Space**, **Arrow Up**, or **tap** to climb. Use **Fly again** to restart.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Choose **Deploy from a branch**, select the default branch and **/ (root)**, then save.

The game will be available at https://Gimmehackcode.github.io/Skyline-Pilot/ after deployment completes.
